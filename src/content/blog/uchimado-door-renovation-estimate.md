以前、[現地調査に立ち会った](/blog/family-home-window-renovation/)実家の窓と玄関のリフォーム。その見積もりが出た。内窓3か所と玄関ドアの交換で、税込119万5000円だ。

補助金とポイントを引けば実質100万円を切る。それでも、やっぱり高く感じる。母からは明日の午前中に契約へ行く予定だとLINEが来たので、その前に見積書4枚を見直した。

## 🪟 内窓は大きな窓2か所とキッチンの出窓

工事するのは、母が普段よくいるキッチンとリビング。キッチンの大きな窓と出窓、リビングの大きな窓の3か所に、YKK APの「ウチリモ」を付ける予定だ。ガラスはガス入りのLow-E複層ガラスになる。

大きな窓2か所は、どちらも高さが約2.2mあって4枚建て。広い方は幅も約3.5mあるので、窓3つといっても結構な大きさだ。カーテンレールは今の場所のままでよく、3窓以上だと標準取付工事費が無料になる特典も付いていた。

![既存の外窓を残し、その室内側に4枚建ての内窓を追加する取付位置の模式図](/images/uchimado-door-renovation-estimate-four-panel.svg)

出窓の方は、正面だけでなく左右にも小さな窓がある。ただ、今回付けるのは棚の手前を仕切る2枚の内窓だそうで、棚を今までどおりには使えなくなる。

## 💰 窓3か所なら補助金を引いて約51万円

窓3か所の明細は税込68万7456円で、補助金17万4000円を引くと51万3456円。全体の諸経費や値引きを振り分ける前ではあるけれど、窓だけならざっくり50万円くらいだ。それなら妥当かなと思う。

工事費も上がっているので、できるだけ2026年の施工例や今の販売価格を調べた。[大きな4枚建てのウチリモ](https://www.madoshop-koberokko.jp/works/works-19560/)で1か所36万9000円という例もあり、寸法や細かな仕様は違うものの、今回の見積もりだけが特別高い感じではなかった。出窓分の約6万6000円も、手前に2枚付ける工事として比べて、気になるほど高くはなさそうだった。

| 項目 | 金額 |
| --- | ---: |
| 工事全体の見積もり（税込） | <span style="white-space: nowrap">1,195,000円</span> |
| 後日振り込まれる補助金（予定） | <span style="white-space: nowrap">174,000円</span> |
| ポイント還元（予定） | <span style="white-space: nowrap">45,000円相当</span> |
| 補助金とポイントを引いた実質額 | <span style="white-space: nowrap">976,000円相当</span> |

ただし、4万5000円分はPayPayポイントなどで戻る予定だ。現金で戻る補助金だけを引くと、負担は102万1000円。100万円以下になるのは、ポイントまで含めた話になる。

## 🚪 玄関の交換は母の希望

俺としては、玄関まではやらなくてもいい気はしている。窓だけなら50万円くらいだと思うと、やっぱり玄関の分が大きい。

ただ、母は今の玄関が金属製で重いのも、古いデザインも替えたいらしい。補助も少し出ると聞いたので、窓と一緒にやってしまいたいとのことだった。ここは母の希望で進める予定だ。

替えるドアはLIXILの「リシェント玄関ドア3」で、K4断熱仕様のG15型。こちらも諸経費や値引きを振り分ける前で、工事費などを含めて約54万2000円だった。[カインズの同じ型の親子ドア](https://reform.cainz.com/point/entrancedoor/1036)も工事費込み52万6000円だったので、玄関も高すぎる見積もりではなさそうだ。

## 📄 補助の確認で母が法務局へ

母は今日、法務局で建物の謄本も取ってきたそうだ。見積もりのときに、古すぎる家だと補助の対象にならないような説明があったらしく、建てた時期を確認するために必要だと言われていた。

実家が建ったのは俺が小学1年生のころで、もう築33年ほど。母からは、登記の日付が平成5年、つまり1993年だったので大丈夫だとLINEが来た。

もっと古かったら内窓だけでは駄目なのか、というのも気になった。ただ、窓の補助の[先進的窓リノベ2026](https://window-renovation2026.env.go.jp/overview/)には、古い家というだけで対象外になる条件はなかった。

別の補助制度の[みらいエコ住宅2026](https://mirai-eco2026.mlit.go.jp/application-for-issuance/trigger-room.html)だと建築時期や窓の性能などで条件が変わり、1991年以前の家では、窓のほかに壁や床などの断熱工事も必要になる場合があるそうだ。

## ✉️ 出窓の枚数だけ担当者に確認

ただ、出窓のところだけは、説明と見積書が違っていた。棚の手前に2枚の内窓を付けると聞いていたのに、書類には「4枚建て」と書いてある。

母にLINEで、2枚建てで注文することと、金額もその内容になっているかだけ確認してもらうよう伝えた。母は「出窓2枚の脇に一枚ずつガラスがあるからじゃないかなぁ」と言っていたが、担当者にも聞いてくれた。

すると、やはり見積書の間違いだったそうだ。明日、差し替えてもらえるとのことで、母からは「よく気づいたね」と返信が来た。

## 📝 まとめ

母は明日の午前中に、見積書を差し替えてもらってから契約する予定だ。金額は安くないけれど、気になったところを担当者にも確認できたので、このままお願いして大丈夫そうだと思っている。
