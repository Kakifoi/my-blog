# kakifoi.net — SNS投稿運用ルール

この文書はX・Instagram投稿の詳細原本。内容ルールはリポジトリ直下の `CLAUDE.md`、PM手順は `.claude/PM-HANDOFF.md`、依頼者向け要約は `.claude/CHAT-PROJECT.md` を参照する。SNS固有の詳細は他文書へ複製しない。

## 共通デフォルト

### 記事URLとUTM

- 記事告知は、本番反映を確認できた記事の**直接URL**を使う。ブログトップへ誘導しない。
- 記事が未公開、または正確なURLを確認できない場合は投稿準備を停止する。存在しないURLを推測しない。
- UTMは記事スラッグから自動生成する。
  - X（post01）: `?utm_source=x&utm_medium=organic_social&utm_campaign=<slug>&utm_content=post01`
  - Instagramプロフィール: `?utm_source=instagram&utm_medium=organic_social&utm_campaign=<slug>&utm_content=profile`
  - Instagramストーリーズ: `?utm_source=instagram&utm_medium=organic_social&utm_campaign=<slug>&utm_content=story`
- 記事URLに既存のクエリがある場合だけ、先頭の `?` を `&` に替える。

### 素材とプライバシー

- 指定された実ファイルを目視し、内容、向き、掲載順を確認する。
- 指定のない画像の追加・削除・差し替え・生成はしない。
- 人物の顔、氏名、住所、バーコード、車両番号、反射、位置を特定できる情報などを確認する。
- 代替テキストは**写真に実際に写っている内容だけ**を書く。感想、宣伝、推測、年齢・性別の推測は入れない。
- 個人情報を消す加工、主要被写体が切れるトリミングが依頼に明記されていない場合は、実施前に別途確認する。依頼に明記済みなら同じ確認を繰り返さない。
- 比率変更で被写体が切れる場合は余白で調整し、生成AIによる補完はしない。

### ブラウザ操作と公開前確認

- ブラウザが対応していれば、ローカルファイルを指定順で直接一括アップロードする。
- ブラウザからファイル選択を実際に制御できない場合だけ、ユーザーへ手動選択を1回依頼する。同じ操作を何度も繰り返させない。
- 素材、本文、代替テキスト、UTM、位置情報をすべて準備してから、**公開前確認を1回だけ**行う。
- 公開前確認では、投稿先アカウント、画像と順番、トリミング、本文、代替テキスト、URL・UTM、位置情報、必要なプロフィールリンク変更を簡潔に示す。
- 既存投稿の削除、個人情報加工、主要被写体が切れるトリミング、位置情報の不一致は、通常の公開前確認とは別に確認する。
- 位置情報は指定施設との完全一致を確認できた場合だけ設定する。候補がなければ位置情報なしとし、似た場所を勝手に選ばない。
- プロフィールリンクは、ユーザーが明示的に依頼した場合だけ変更する。
- 公開はユーザーの最終承認後に行い、公開後は投稿内容とリンクを確認して、確認済み項目を簡潔に報告する。

### 投稿後の指標

- 48時間後・7日後の指標確認は、現在はユーザー自身が行う。通常の投稿依頼には含めない。
- ユーザーから明示的な依頼がある場合だけ、投稿作業とは分けて別タスクまたはautomationとして扱う。

## X

- 画像は原則として元の比率を維持する。主要被写体を切る加工はしない。
- 投稿本文、画像、代替テキスト、記事の直接URLとX用UTMを準備する。
- 画像追加・差し替え・生成、ハッシュタグやCTAの無断追加はしない。
- 公開前に投稿先アカウント、本文、画像、代替テキスト、URL・UTMをまとめて確認する。

## Instagramフィード

- カルーセルは指定順を厳守し、全画像を同じ比率にそろえる。
- 原則は4:5。正方形指定がある場合は1:1を使う。
- 縦長の書類やメニューなどは重要部分を切らず、必要なら余白を使う。生成補完はしない。
- 本文、代替テキスト、位置情報、記事告知時のプロフィール用UTMを準備する。
- 公開前にカルーセル全体の順番と各画像の切れ方をまとめて確認する。

## Instagramストーリーズ

- 素材はブラウザ操作前に9:16で準備する。主要被写体を避けて文字やリンクスタンプを置ける余白を確保する。
- 指定画像、掲載順、文言、記事の直接URLとstory用UTMを準備する。
- PCブラウザで同じ操作を繰り返し失敗しない。UI制約で完成できない場合は、9:16素材、掲載文、リンクURLをそろえ、スマホでの配置・公開へ1回で引き継ぐ。
- スマホ引き継ぎ時は、画像順、各掲載文、リンクスタンプの文言とURLを1つの手順にまとめる。
- 公開前に全ストーリーズの画像、文字位置、リンクスタンプをまとめて確認する。

## 短縮依頼テンプレート

共通デフォルトは自動適用するため、通常は以下だけ指定すればよい。記事固有の禁止事項や加工条件があれば「特別な注意」に追記する。

```text
SNS: X / Instagramフィード / Instagramストーリーズ
記事スラッグ:
投稿の切り口:
画像と掲載順:
投稿本文: 指定文 / おまかせ
位置情報: 施設名 / なし
プロフィールリンク変更: あり / なし
特別な注意:
```
